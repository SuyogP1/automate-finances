# 💰 Automate Finances

A simple personal finance dashboard built with **Python, Pandas, and Streamlit**.

## 🚀 Live Demo

[**View the Live App →**](https://automate-finances.streamlit.app/)

## ✨ Features

* Upload transaction data from a CSV file
* Separate expenses and payments
* Automatically categorize transactions using keywords
* Create custom expense categories
* Edit transaction categories directly in the dashboard
* Save category and keyword mappings
* View expense totals by category

## 🛠️ Tech Stack

* Python
* Pandas
* Streamlit
* Plotly
* JSON

